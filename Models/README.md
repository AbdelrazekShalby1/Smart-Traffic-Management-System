# Detection models

The supplied project includes these model artifacts:

| File | Used for |
| --- | --- |
| `yolo11n.pt` | Default vehicle detector |
| `yolo11s.pt` | Alternative YOLO model |
| `Emergency_Detection.pt` | Emergency vehicle detection |
| `license_plate_detection.pt` | License plate detection |

Model training provenance, datasets, evaluation metrics, and redistribution licenses
were not supplied. This repository does not assign a new license to these artifacts.
Consult the relevant model owners before reuse or redistribution.
`Emergency_Detection.ipynb` contains the supplied training notebook with saved outputs removed.
